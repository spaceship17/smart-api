## Introduction

One of the most important steps when learning any programming language—after mastering primitive data types, control flow, and the basics—is understanding how APIs work. APIs are the building blocks of modern programming, whether you're working with your own data or orchestrating larger projects.

This repository is a small effort to help you get started with APIs. Here, you'll find simple, practical examples using two different APIs:

- **GitHub API:** Learn how to fetch the most-starred repositories and compare the popularity of programming languages based on public contributions.
- **Hacker News API:** See how to interact with another popular public API.

Both APIs are straightforward to use and require no API key for basic queries (though keep in mind there are rate limits—if you want to dig deeper, you'll need to use an API key).

Feel free to clone this repo, play around, and extend the examples to other languages or categories. Pull requests and suggestions are always welcome—let's make this a better resource together!
